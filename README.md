# 🍽️ Restaurant Management System (HungryStreet)

A complete web-based Restaurant Management System developed using **PHP, MySQL, HTML, CSS, and JavaScript**.
This project helps manage restaurant operations like menu browsing, cart system, table booking, and admin dashboard.

---

## 🚀 Features

### 👨‍🍳 User Side

* Browse food menu (Veg items)
* Add items to cart 🛒
* Book tables online 📅
* View restaurant homepage

### 🔐 Admin Panel

* Admin login/logout system
* Manage dashboard
* Handle orders and bookings
* Database integration

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Tools:** XAMPP / WAMP

---

## 📂 Project Structure

```
hungrystreet/
│
├── coding/
│   ├── admin/              # Admin panel files
│   ├── menu/               # Menu and cart system
│   ├── book table/         # Table booking module
│   ├── index.php           # Main homepage
│   ├── kitchen_jungle.sql  # Database file
│
└── README.md
```

---

## ⚙️ Installation & Setup

1. Install **XAMPP / WAMP**

2. Move project folder to:

   ```
   htdocs/
   ```

3. Start:

   * Apache ✅
   * MySQL ✅

4. Import database:

   * Open phpMyAdmin
   * Create database
   * Import `kitchen_jungle.sql`

5. Run project:

   ```
   http://localhost/hungrystreet
   ```
